# Sonora — Suno Link Helper

A small, mobile-friendly link helper for Suno share links and direct audio URLs.

## What it does
- Validates and recognizes Suno share URLs.
- Opens Suno tracks so creators can use official download/export options available to their account.
- Recognizes direct audio URLs and lets users open/save those files when permitted.
- Runs in the browser and does not store submitted links.

## Important limitation
A Suno share link is not necessarily a direct audio-file URL. This app does not scrape private endpoints, bypass paid features, or circumvent platform access controls. For Suno tracks, use the download/export options available to your account.

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000.
